# Ralphy 🌍

A personal travel blog and vlog built with:
- **Backend**: .NET 9 Web API
- **Frontend**: React + Vite (coming soon)
- **Database**: PostgreSQL 16
- **Storage**: Cloudinary
- **Containerization**: Docker

## About
A personal project by Ralph Alcaide — a Filipino traveler and developer 
from Occidental Mindoro, documenting journeys through drone and phone footage.
